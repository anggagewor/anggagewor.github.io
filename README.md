# anggagewor.github.io

Personal portfolio site — built with Jekyll + custom HTML/CSS. Dark mode, modern, fast.

## Stack
- Jekyll (GitHub Pages)
- Custom HTML/CSS (no framework)
- Inter + JetBrains Mono fonts
- Pure CSS animations

## Local Dev
```bash
gem install bundler jekyll
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`

## Deploy
Push to `main` — GitHub Pages handles the rest.
